# 记忆点 APP
一个基于uniapp的开源本地APP， 一个背诵文章的app纯前端app，支持背诵计划，文章阅读， 背诵效果， 关于app，四大功能。
- 文章阅读：文章从github pages里读取，一个目录，可以过滤标题，有继续阅读功能，支持书签
- 背诵计划：可以管理计划，每个计划添加文章或文章中的段落
	①背诵方式：将段落拆分成词语或短句，然后让用户排列组合成正确的顺序，根据组合结果打分， 显示花费时间，根据难度隐藏部分词句，用户通过拼音首写字母输入。
- 背诵效果：可以查看每个计划的背诵效果，包括正确答案，错误答案，正确率，背诵时间，遗忘率（根据遗忘曲线估算），记忆率（根据遗忘曲线和学习效果估算）
- 关于app：介绍app的功能，如何使用，如何贡献代码，如何反馈问题，捐献app的开发者

# 开发要求
- 代码编写要专业
- 界面设计要专业
- 功能使用要简单
